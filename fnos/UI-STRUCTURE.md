# 飞牛播放器和音箱设置

## 播放入口与音箱范围

飞牛桌面默认打开共享 Flutter 播放器。每个播放标签页通过实例 ID 读取曲目、封面，并将控制命令发给该实例。右上角三点菜单的「设置」打开共享 Flutter 设置面板，可查看接收协议、诊断、日志和更新。

右下角飞牛菜单有两个入口，均可在单音箱配置下使用。

- 「切换音箱」打开 `speakers.html?instance=<id>#rooms`。卡片显示房间及当前曲目，点击卡片打开其播放器。带已绑定输出的卡片提供「音量曲线」。独立实例卡片有「编辑实例」，主接收器有「管理输出」。列表按可用宽度平铺，音箱较多时使用紧凑卡片，超出视口可纵向滚动。
- 「新建实例」打开 `#new`。选择输出、填写投送名并保存后，服务器启动独立实例。成功后进入该音箱的 `#curve`。可直接采用现有曲线。回访时主接收器有多个输出需手动选择，独立实例自动选中自己的设备。删除的实例或已变更的绑定无法提交旧页面的修改。

这些音箱视图共用封面背景和随卡片圆角计算的位移滤镜。曲线编辑器按设备保存。预览滑块显示发送端逻辑音量对应的输出幅度，实际声压取决于声卡、功放和音箱。

## 主接收器输出

音箱选择页的「主接收器输出」在主接收器休眠时仍可使用。它支持同步输出分配、响度、延迟、采样率、测试音、全局衰减和输出组合。绑定独立实例的设备会标明所属音箱。服务器在保存时核对原始音频配置，多个标签页同时编辑时会提示重新加载。

## 兼容旧书签

根入口只做跳转并保留查询参数。旧概览进入播放器，旧接收与设置进入共享设置，旧音频进入音箱输出管理，旧曲线进入绑定实例的曲线页。两种架构的 FPK 使用同一份前端资源清单。
