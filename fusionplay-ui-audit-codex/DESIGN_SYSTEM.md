# FusionPlay UI 组件约定

| 使用位置 | 组件及规则 |
|---|---|
| 上一曲、下一曲、音量、顶部动作 | LiquidGlass control。药丸半径 999，由实际尺寸裁切。剪裁、采样和触摸区共享宿主。按压或 hover 更新局部高光，遥控器使用 RemoteFocusFrame。 |
| 信息和设置子卡片 | 静态卡面叠在 panel 内，卡片半径 22，行半径 16。设置卡片填充 0x24151822，行高亮 0x1AFFFFFF，分隔线 0x0DFFFFFF。内部列表滚动复用外层玻璃。 |
| 菜单和设置 | 一个 FusionMorphOverlay 在锚点、菜单、设置之间插值形状与位置。菜单展开 260 ms，设置展开 320 ms，关闭 240 ms；模糊随设置展开进度连续变化。 |
| 关于、更新以及结果提示 | 路由使用 showGlassDialog；popup 共用 panel 的深色规格。更新确认的说明允许内部滚动，忙碌状态使用独立进度内容。 |
| 主操作与标签 | 白色圆形播放/暂停维持视觉优先级。协议标签为小型半透明文字标签。歌词使用字体大小和亮度区分当前行，保持在采集边界外。 |

基础光学参数在 GlassSpec，控制和面板默认折射 .85、高光 .30、厚度 14 逻辑像素。颜色、模糊、阴影和边缘强度按等级配置。Popup 可以针对面积缩短光学厚度。设置文字、输入焦点、开关、分隔线等 token 在 SettingsView 的 _GlassStyle。按钮按压和释放分别使用 FusionMotion 的 120/160 ms；降低动画设置应保留激活、选择和关闭语义。

布局使用逻辑像素。先为传输按钮和间距留宽，再分配封面。紧凑行保留完整 40 px 进度交互高度，通过移动文字调整视觉距离。标题使用有限行数和省略；长更新说明和设置页有独立滚动区。TV 入口保留 overscan、安全区和方向键遍历。
