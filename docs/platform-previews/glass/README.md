# 飞牛玻璃预览

播放器截图来自 Flutter Web 发布构建。管理页截图来自飞牛服务提供的页面，在 Chromium 中以模拟的播放状态和测试封面渲染。音频页分别记录浅色和深色主题。截图没有使用真实 NAS 或音频输出设备。

## 折射对照

[开启边缘折射](glass-on.png) · [将位移强度设为零](glass-off.png)

在 1100 × 680 的 Chromium 窗口打开深色音频页面，将背景替换为间距 6 CSS 像素、角度 97 度的黑白条纹，并让第一张卡片的填充透明。保持页面静止，在原始强度 14 和 SVG feDisplacementMap 强度 0 下分别截取该卡片。两次保留相同的模糊、文字和布局。

在两张 400 × 144 截图中剔除上下各 12 像素后，左边缘第 2 至 8 列的 RGB 通道平均绝对差为 22.66（满值 255），去掉左右各 35 像素后的中央区域为 0.013。位移图按面板实际 CSS 像素宽高绘制，避免浏览器按错误的视口计算百分比尺寸。该对照验证此 Chromium 环境下的空间采样效果。
