## FusionPlay Android 1.7.3

- 播放器、菜单、设置和浮层使用共享封面背景与折射材质，调整封面悬浮投影及播放按钮行的位置。
- AirPlay 读取发送端提供的 DMAP 曲目标识，分辨同曲标题更新与切歌。收紧“标题即歌词”的判断，避免同专辑连续曲目误入歌词视图。歌词可用性取决于发送端。
- DLNA 相对封面地址按当前媒体地址解析。播放器接受与妙播接收端相同大小上限的内嵌封面。

- 封面解码失败时保留上一张已显示的封面，并在后续播放状态更新时重试。

本次验证包含自动化接收状态与 Flutter 播放页测试。未进行本版本的手机到接收器真机投送或 Android GPU 性能测试。
