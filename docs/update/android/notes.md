## FusionPlay Android 1.3.7

### 播放页
- 修复手机横屏内容被底部 dock 遮挡/重叠；高度 <430px 自动切换紧凑 chrome，空态提示始终在 dock 上方。
- 液态玻璃改为每组件独立静态 shader，默认不再逐帧刷新，修复部分 Android Impeller 机型玻璃一直闪烁的问题；Windows/测试环境继续使用毛玻璃回退。
- 右上三点菜单改为真正的容器 morph：圆形按钮先淡出，玻璃容器保持按钮右上角与圆弧，向左下展开成圆角菜单；点设置再 morph 成右侧半屏面板，关闭时逐层收回。
- 顶部只保留音频来源（AirPlay 2 / 小米妙播 / DLNA），不再显示音质/码率胶囊；播放按钮在进度条与屏幕底部之间垂直居中。
- 新增 TV/遥控器适配：Leanback 启动入口 + TV banner、电视自动识别、overscan 安全边距、4px 焦点框 + 焦点放大、设置默认焦点避开输入框，电视设置面板宽度上限 720（仍不超过半屏）。

### 设置
- 设置界面重写为深色液态玻璃：右侧半屏玻璃面板，半透明分组卡片、白色文字层级、单色玻璃开关（白底深色滑块）与白色勾选，不再使用绿色 accent 和白色实心卡片。
- 标题栏改用 Flutter 官方 `PinnedHeaderSliver`：内容真正从标题栏下方滚过，底部不再有 1px 硬分割线；顶栏使用与面板同色系的模糊材质，避免更深的实色条。
- 所有原有设置项、文案、顺序、快捷键、D-pad 焦点与检查更新流程保持不变。

### 安装
- 版本 1.3.7 / versionCode 10307，固定 release 签名，可直接覆盖 1.3.6。
- 1.3.4 及以上可在「设置 → 检查更新」直接升级；1.3.3 及更早需手动安装一次。
