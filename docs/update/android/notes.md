## FusionPlay Android 1.3.5

### 新增：歌词显示 + 逐字高亮

- 播放页新增「歌词」入口（遥控器可聚焦）：进入后标题缩小、封面平滑缩小左移，中间显示歌词，进度条与控制栏保留。
- **妙播（MiPlay）**：解析手机下发的歌词（yrc 逐字、增强 LRC、QRC 风格毫秒时间），当前行放大加粗，**按字/词卡拉 OK 式填色**。
- **DLNA**：支持 LRC / 嵌入歌词 / `lyricsURI` / `.lrc` sidecar，行级高亮；带词时间戳也能逐字。
- 自动居中滚动；手动滚动后暂停自动滚动 4 秒，并出现「回到当前」按钮。
- 状态齐全：加载中 shimmer、无歌词空态、非同步歌词静态列表。
- 全部动画遵循系统「减少动态效果」设置。

### 播放页动效优化

- 歌词模式进入/退出 fade + 位移 + 轻微缩放；
- 播放/暂停图标 morph、进度条数值平滑、控制栏错峰入场、播放中封面轻微呼吸感；
- 歌词行切换 200ms 缓动，逐字进度帧间平滑（本地时钟外推，减少 10Hz 状态跳变感）。

### 其他

- 继续包含 1.3.4 的在线更新、妙播/DLNA 兼容性修复。
- 版本 1.3.5 / versionCode 10305，固定 release 签名，可直接覆盖安装 1.3.4。

### 说明

- 歌词格式来自发送端；若某台手机/某个 App 显示不出歌词，可反馈 `media_info` 的歌词样本，便于补充解析。
