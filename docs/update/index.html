安装

1. 下载 APK 后，在文件管理器中打开并允许“安装未知应用”；
2. 覆盖安装会保留设置与数据（同一签名证书才能覆盖升级）；
3. 从 1.2.6 或更早的 debug 签名版本升级时，需要先卸载一次旧版本；
4. 手机与电脑/音箱需要在同一局域网内。
