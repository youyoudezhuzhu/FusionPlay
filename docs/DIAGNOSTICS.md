# FusionPlay 诊断日志

发生异常后请尽快导出，并附上大致时间、平台、投放协议和音箱实例名。普通运行日志按大小轮转。警告和错误另有小容量记录，便于在高频进度或调试输出之后查找。运行日志与导出缓存分别管理。

| 平台 | 在哪里取 | 应用管理的空间及清理 |
| --- | --- | --- |
| Android | 三点菜单或设置中的「导出日志」。ZIP 含版本信息、结构化日志、按协议分类的记录，以及当前进程可访问的 logcat。 | 日常日志 5 × 4 MiB，错误历史 2 × 256 KiB。分享缓存最多 3 份、合计预算 48 MiB，保留 3 天。应用启动、运行期间每小时和再次导出时清理分享缓存。构建 ZIP 时会临时使用额外空间。 |
| Windows | 菜单导出到 FusionPlay 的 `exports`。后台起不来时可直接取 `%LOCALAPPDATA%\FusionPlay\logs\player.log` 和同目录的 `player.previous.log`。 | 后台日志 5 MiB、错误历史 256 KiB。Flutter 单段约 256 KiB，保留两段。导出文本最多 3 份、合计 8 MiB、保留 3 天，启动、每小时和导出时清理。 |
| 飞牛 x86_64 / ARM64 | 设置 → 高级诊断 → 运行日志 → 下载。输入搜索词只影响预览和复制。下载包含服务启停输出、主接收器、各已配置音箱和当前浏览器错误，按来源分段。 | 主接收器最多 5 MiB，每个额外音箱最多 1 MiB，各进程另有 256 KiB 错误历史。服务标准输出约 5 MiB，每 30 秒检查一次。已移除音箱的历史日志合计最多 4 MiB，启动和每小时清理，最多保留 7 天。 |

三个宿主启动时和运行期间会清理超过 7 天未写入的接收器日志文件。活跃文件按字节数轮转，单条旧记录可能随文件保留。Windows 和飞牛限制单条后台输出为 16 KiB。飞牛每次下载读取各来源最近的一段，日志输入总量最多 2 MiB；浏览器另外保留最近 7 天的 32 条错误。下载由浏览器保存，不会在 NAS 上再留一份导出文件。用户主动保存或转发的文件由用户管理。

Android 关联信息包括运行标识、序号、协议和事件。Windows 和飞牛会记录协议后台线程、命令失败与 Rust panic；Windows 另收集侧车启动失败和 Flutter 异常。飞牛主进程记录异常退出的音箱 ID、PID 和退出状态。飞牛服务无法启用时，可在 NAS 上直接取 `/var/apps/fusionplay-fnos/var/app.log` 及应用中心的启用错误。

播放器错误会限制文本和堆栈长度；Windows 和飞牛诊断输出会遮盖识别到的媒体 URL、Authorization、Cookie 和令牌值。Windows 导出保留封面和歌词的存在状态、歌词长度等线索，省略封面二进制内容。

设备突然掉电、操作系统直接终止进程或磁盘不可写时，最后一次错误可能来不及落盘。此时应用最后一条记录的时间、退出状态和系统日志可以一起定位故障。飞牛浏览器错误由复现问题的浏览器保存，导出时请使用同一浏览器。
