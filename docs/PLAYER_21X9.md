## 1. 当前实现

### 结构

```
全屏背景（沿用现有封面动态氛围背景，未改 Shader/参数）
└─ 顶部状态行：协议/音质（左） + 歌词显隐 + 更多菜单（右）
└─ 横向双栏
   ├─ 左：半透明玻璃播放面板
   │  封面 → 标题 → 歌手/专辑 → 细进度条 + 当前/剩余时间
   │  → 上一曲/播放/下一曲 → 底部音量胶囊
   └─ 右：无卡片、直接铺在背景上的沉浸式歌词
```

- 有歌词：左侧玻璃面板 + 右侧歌词，不再使用纵向 Column 堆叠。
- 无歌词/隐藏歌词：左侧大封面 + 右侧玻璃信息/控制面板，不出现空白歌词列。
- 不再有独立底部 Dock；音量移入左侧面板最下方。
- 不再使用 `FittedBox.scaleDown`；不再用固定高度阈值决定 compact。
- 不新增 shuffle/repeat/queue/output 假按钮；随机/循环只在协议真实支持时才具备（当前 UI 不伪造）。

### 动态宽度

`_liquid21PanelWidths`：

- 左栏 preferred = 可用宽度 × 40%；
- 左栏下限 = `min(260, 宽度×40%)`，上限 = 宽度×46%；
- 双栏间距 = 可用宽度×2.2%，限制在 12–28；
- 右栏 = 剩余宽度，保证歌词最小可读宽度。

因此 840、1080、1280、1920 宽下比例会随可用宽度变化，不是写死像素。

### 高度预算与封面

左侧面板先扣除：

- 页面外边距 14/0/20/10；
- 顶部状态行；
- 面板内边距（紧凑 10 / 普通 16）；
- 封面下方信息、进度/时间、控制、音量胶囊和间距（紧凑预留 224px，普通预留 250px）。

然后：

```dart
cover = min(panelWidth - padding*2, max(56, panelHeight - reserved)).clamp(56,300)
```

所以 21:9 小高度优先缩小封面与辅助信息，播放按钮和音量滑块保持最小可操作高度，不通过整页缩放掩盖溢出。

### 玻璃

- 复用项目现有 `LiquidGlass`，左面板为 `GlassLevel.panel`。
- 为符合“透、柔、克制”，播放面板使用降低的 `specular: .22`、`refraction: .65`、`thickness: 12`、深色半透明 tint；没有额外叠加旧版模拟高光，也没有大面积白色亮边。
- 歌词区域无玻璃卡片。

### 保留功能

AirPlay/MiPlay/DLNA、元数据、封面、播放暂停、上一曲/下一曲、进度/Seek 能力、音量/静音、同步歌词、逐字歌词、显隐歌词、AirPlay 标题歌词、协议/音质、菜单、遥控器焦点、键盘、触摸、减少动画均由真实状态驱动。
